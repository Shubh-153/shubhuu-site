User reported: "in creative html when on phone there is extra space like horizontal scrolling is there so there are some options on the right side which is getting hid how to fix that ?"

Root cause identified: `.dev-message { white-space: nowrap; }` tooltips at ~400px wide force page-wide scroll and hide `.nav-right` (mute/mode toggles) off-screen on phones < 600px.

Multi-part fix applied:
- Hide `.dev-message-container { display: none; }` under 600px
- Add `nav { flex-wrap: wrap; gap: 16px; }` so nav wraps instead of overflowing
- Add `html { overflow-x: hidden; }` + `body { max-width: 100vw; }` safety net
- Add `.nav-right { margin-left: auto; }` to pin toggles right even when wrapping

Regression caught: User reported "but isnt the toggles are in between now ?" — `justify-content: space-between` + `flex-wrap: wrap` collapsed `.nav-right` to line-start. Fixed with `margin-left: auto`.
